## Название

MoneyGraph Investigator — UNRU AI

## Описание для формы

Локальный инструмент для AML-аналитика: превращает обезличенную сеть из 2248 узлов в объяснимую очередь проверки. Из трёх parquet автоматически строит направленный граф, назначает роли по документированным правилам, выделяет кластеры и экспортирует три обязательных CSV с TOP-50. Интерфейс показывает связи, суммы, альтернативные гипотезы, ограничения данных и следующий полезный запрос.

Отдельно учитывает обрыв на четвёртом колене и неполную историю seed. Read-only AI-агент вызывает инструменты, объясняет наблюдения и ищет общих downstream-кандидатов для 1–5 GID. Без ключа доступен проверяемый архив реальных AI-ответов. Дополнительные локальные проверки: чувствительность правил и контрфактическое удаление TOP-N. Выводы — гипотезы для проверки, не утверждения о виновности.

Python 3.12 + NetworkX + FastAPI + статический интерфейс. CPU, без GPU; основной сценарий воспроизводится без аккаунтов и API-ключа. Запуск, правила, архитектура, ограничения и тесты — в README.

## Соответствие ТЗ

| Требование | Артефакт |
|---|---|
| Один запуск от parquet до CSV | `python -m moneygraph.pipeline` |
| Роль/score/evidence всех 2248 узлов | `outputs/nodes_roles.csv` |
| Объяснимые критерии | README: правила и пороги, карточки узлов |
| Кластеры | `outputs/clusters.csv` — 91 кластер |
| TOP ≥20 и просмотр любого GID | `outputs/top_nodes.csv` — 50, локальный UI |
| Схема решения | Mermaid в README |
| Демо 5 минут | `docs/DEMO_5_MIN.md` |

Полностью реализованы пять optional: обрыв графа; TOP-N removal; AI-ассистент; карточка узла; оценка полноты/следующий запрос. Temporal, повторяющиеся маршруты и отдельный детектор аномалий не заявляем реализованными.
