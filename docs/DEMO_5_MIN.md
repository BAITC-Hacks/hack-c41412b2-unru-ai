## Короткие ответы на вопросы

- **Где AI?** Выбор инструментов и объяснение результатов с возражениями. Граф, роли, BFS и рейтинг рассчитывает локальный движок.
- **Почему без accuracy?** Организатор не выдал размеченные роли. Проверяем правила, контракты, ограничения и чувствительность, не заявляем доказанную точность ролей.
- **Почему 35 компонент, а в ТЗ 16?** 16 компонент по рёбрам плюс 19 изолированных seed из nodes.parquet.
- **Что с 354?** 354 узла с положительным входом отдают больше наблюдаемого входа; ещё 23 seed с нулевым наблюдаемым входом дают общий счёт 377.
- **Почему это полезнее одного графа?** Есть очередь действия, основания, альтернативы и конкретный следующий запрос, а не только визуальная связность.
- **Что при миллионе узлов?** Более компактный графовый движок и пакетный расчёт; UI сохраняет ограниченные окрестности. Это план в README, масштаб не протестирован.
- **Нет интернета?** Расчёт, граф, CSV, диагностика и архив работают. Для нового LLM-ответа нужен интернет и свой ключ.
