## Ограничения checkpoint

Только локальный 1-hop graph с рёбрами, инцидентными выбранному узлу. Нет общего overview и 2 hops. Максимум по умолчанию 160 узлов (API до 250), усечение всегда явно маркируется. В текущем наборе максимум 117 узлов на такую окрестность, поэтому ни одна не усекается по умолчанию. Подписи соседей сокращаются/скрываются на плотном графе, точные gid всегда есть в подсказке, карточке и таблице.

Сервер локальный, без многопользовательской авторизации; не заявляется production-готовность. Temporal и runtime OpenAI не реализованы. Публичное развёртывание и отправка решения через платформу не выполнялись.
