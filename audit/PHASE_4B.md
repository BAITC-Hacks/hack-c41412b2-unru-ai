## Определение и границы

Формула из запроса пользователя: entropy effective number по распределённым
кредитам внешних seed на последних входящих ветвях. Для каждого seed вклад
суммарно 1. Для target v множества вычисляются в G без v: возвраты через v
не создают новые входы; собственный seed исключён из convergence, но сохранён
в исходном reachable_seed_count. Обычные upstream-циклы разрешены, обход
останавливается visited-множеством. Пустая поддержка даёт 0, не доказательство
отсутствия внешних путей. Входящая оценка допускается и на depth=4.

Формула не измеряет независимость путей и может дать больше ветвей, чем seed.
Последние ветви могут повторно разойтись после общего upstream участка.
Глобальные seed-множества без исключения target здесь дали бы ложные входы
из возвратных циклов; это уточнение реализации явно раскрыто в README.
