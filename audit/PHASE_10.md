# PHASE 10 — локальная методика расчёта

Добавлена `/methodology`: 17 разделов, общая навигация, якорные ссылки из
карточки, разложение силы роли для произвольного существующего GID.

## Согласованность

- Предикаты, веса, слагаемые и вспомогательное выражение transit извлекаются
  из AST `roles.classify_row`; приоритет — из `roles.assign`.
- Условия/потолки достаточности и параметры Louvain извлекаются из кода;
  очереди используют существующие константы.
- Числа графа, кластеров, Stability, Pattern Analysis и удаления TOP-N берутся
  из текущего Store и рассчитанных результатов.
- Поясняющая проза защищена source-hash guard: изменение аналитических модулей
  требует пересмотра документации. Это проверка изменения источника, не
  автоматическое доказательство правильности любого текста.
- Проверены все пять сил ролей всех 2248 узлов против действующего классификатора.
  Для отображения используем исходные поля Store; экспортные процентили округлены,
  поэтому сравнение с сохранённой итоговой силой имеет допуск 1e-8.
- Технические имена ролей, полей, инструментов, PageRank, Louvain, GID и выражения
  Python намеренно сохранены в технических блоках; основные названия русские.
