Только UI: отдельный scoped workspace.css, ограниченный workspace 720–750 px,
пять вкладок инспектора, независимая прокрутка, компактная шапка и KPI,
читабельная типографика, раскрываемый кластер, четыре before/after показателя
TOP-N с подробностями под раскрытием. Масштабирование и прокрутка графа сохранены.
Страница методики, архив, Python, данные, CSV и существующие API не изменены.

99 Python tests + 17 JS checks (13 прежних и 4 проверки вкладок:
сохранность всех секций, единственная активная панель, клавиатура/фокус,
следующий запрос в обзоре и данных). Проверка синтаксиса app.js пройдена.

Браузер: 1440×900, 1536×960, 1728×1117, 1024×768, 390×844.
Нет горизонтального scroll страницы и видимого текста мельче 12 px.
От workspace до устойчивости сети 18 px. Измерения и скриншоты — ui-polish/.
Проверены точный длинный GID, альтернативная роль, depth=4, окрестность с
73 соседями, вкладки паттернов и устойчивости, TOP-10, zoom + / fit.

Ограничения: на tablet инспектор под графом; на mobile блоки последовательно,
поэтому страница длиннее. Большие таблицы/граф при увеличении прокручиваются
внутри собственных областей. Весь анализ не помещается на первый экран;
видны KPI, очередь, граф и верх инспектора.
