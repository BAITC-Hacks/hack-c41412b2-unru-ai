# PHASE 9 — русификация интерфейса и starter.py

2026-09-23. Выполнено по приложенным участником инструкциям.

Организаторский `audit/source/starter/starter/README.md` описывает заготовку
с пустыми ролями. Он не устанавливает обязательное имя точки запуска готового
продукта. Добавлен наш корневой `starter.py`: pipeline → stability → patterns →
локальный сервер. `--no-ui` выполняет только расчёт, параметры `--data`, `--out`,
`--host`, `--port`. Зависимости устанавливаются по прежнему requirements.txt.

Русские подписи применяются только к отображаемому DOM: роли, очереди, статусы,
гипотезы, исходные узлы, колена, ограничения, временные признаки, ИИ-панель и
архив. Символ валюты ₸, PageRank в раскрываемых подробностях. Brand MoneyGraph
Investigator / HackAlem / UNRU AI сохранён. Поля форм и передаваемые значения,
API/CSV/enum, ссылки, файлы и расчётная логика не переводятся.

Словарь меняет названия терминов в отображаемых архивных ответах. Для проверки
есть раскрываемая исходная запись без замен и прежнее скачивание raw JSON.
Исходные ответы/манифест/SHA-256 не изменялись. Это не новые вызовы модели.

Проверки: 93 Python tests; 3 AI renderer + 4 pattern renderer + 6 localization
checks. Новый integration test запускает starter.py из другого cwd, проверяет
SHA-256 трёх CSV и полноту обеих диагностик. Полный стартер запущен на 8011
без ключа с окружением, установленным по README; интерфейс доступен.

Браузер: поиск точного ID; русские роли/статусы и граница depth=4; архив с
оригинальным ответом; поля пользовательского ввода сохраняют английские
технические строки без замены. Поиск английских видимых терминов использован
для доработки словаря. Разрешённый остаток: бренд, ID, OpenAI/API, название
модели, PageRank в подробностях, JSON/SHA-256 и исходная техническая запись.
Никаких новых отправок в OpenAI. Ошибок JS не обнаружено.
